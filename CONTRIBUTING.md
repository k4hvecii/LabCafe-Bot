# Contributing

This repository is being prepared for its first open-source release. The project license and contribution terms are not approved yet; do not treat this preparation as a license grant. Code contribution intake will open after the maintainer chooses a license.

Report reproducible, non-sensitive bugs using an issue: expected/actual behavior, sanitized steps, Node version and OS. Discuss substantial changes first. Never include production tokens, logs, user data or database dumps.

Use a separate test bot/server. Install with `npm ci`; run `npm run check`, relevant tests, and `npm run build`. Run the full suite for authentication, permissions, persistence, or shared infrastructure changes. Describe changes and test results in a small pull request. Update Turkish and English together for visible copy. Avoid unrelated refactors and new dependencies without justification.

The maintainer reviews changes before merge. No response-time commitment, release cadence, contributor count, or historical contribution activity is claimed. After license approval, contributions must be yours to submit and compatible with the chosen license; retain third-party notices.
